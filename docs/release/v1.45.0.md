# v1.45.0 — 폰에서 탭으로 세션을 옮겨 다닌다

폰 화면 위쪽에 세션 탭 줄이 생겼다. 다른 세션으로 가려고 목록에 나갔다 들어올 필요가 없다. Android 뒤로가기도 고쳤다.

## 바뀐 것

- **세션 탭 줄**: 세션 화면 헤더 아래에 열린 세션이 칩으로 늘어선다. 칩을 누르면 그 세션으로 바로 옮겨 간다.
  - 칩 순서는 PC 앱의 세션 순서와 같다. 상태가 바뀌어도 칩이 자리를 옮기지 않는다.
  - 이름이 같은 세션은 폴더명을 덧붙여 구분한다.
  - 맨 끝의 **+**를 누르면 새 세션 폼이 열린다.
- **대기 N**: 입력이나 승인을 기다리는 세션이 있으면 탭 줄과 세션 목록에 버튼이 뜬다. 누르면 기다리는 다음 세션으로 간다. 기다리는 세션의 칩은 테두리로 눈에 띈다.
- **세션 목록 정리**
  - 기다리는 세션은 맨 위 "대기 중" 묶음에 모인다.
  - 줄마다 상태 점과 에이전트 종류·worktree 브랜치가 나온다.
  - 줄 높이를 키워 누르기 쉽게 했다.

## 고친 것

- **Android 뒤로가기가 PC 목록으로 빠졌다**: 이제 세션에서 누르면 세션 목록으로, 한 번 더 누르면 PC 목록으로 간다. 알림으로 세션에 들어온 경우도 같다. 탭으로 세션을 여러 번 옮겨도 한 번이면 목록이다.

## 검증

- 단위 테스트를 추가했다: 탭 줄, 대기 세션 찾기, 뒤로가기, 목록 묶음.
- Electron E2E 33개를 통과했다. 폰 크기 창에서 탭으로 다른 세션에 옮겨 가 입력하고, 뒤로가기로 세션 목록에 돌아오는 과정을 확인한다.

폰 화면은 PC가 보내 주는 페이지라서 데스크톱 앱만 업데이트하면 된다. 폰 앱(0.2.0)은 바뀌지 않았다.
