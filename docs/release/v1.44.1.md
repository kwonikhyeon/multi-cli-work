# v1.44.1 — 작업표시줄 진행률 설정 저장 수정

설정 › 일반의 작업표시줄 진행률 토글이 저장되지 않던 버그를 고쳤다.

## 고친 것

- **작업표시줄 진행률을 끌 수 없었다**
  - 설정 › 일반에서 이 토글을 바꾸면 main이 저장 요청을 거부했다. 설정 변경을 검증하는 허용 목록에 이 항목이 빠져 있었기 때문이다.
  - 이제 허용 목록에 넣었고 값이 참·거짓인지도 확인한다. 끄면 작업표시줄 아이콘의 진행률 표시가 사라진다.

## 검증

- 단위 테스트를 추가했다: 이 설정의 저장과 잘못된 값 거부.
- Electron E2E `desktop.spec.ts`(27개)를 통과했다. 구독 사용량 게이지 테스트는 실행 시각에 따라 실패하는 일이 있었다. "초기화까지 남은 시간"이 1시간 안이면 몇 분이든 통과하도록 고쳤다.

폰 앱(0.2.0)은 바뀌지 않았다.
