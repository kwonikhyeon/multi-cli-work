# v1.45.1 — 페이지 탭을 이름 바로 옆에 배치

폴더·작업공간·숨김 화면의 페이지 탭을 이름 바로 다음으로 옮겼다. 이름과 탭 사이는 일정한 간격을 두고, 레이아웃 선택·새로고침·세션 실행 버튼은 오른쪽에 유지한다.

- 긴 이름은 말줄임으로 표시하며, 좁은 헤더에서도 탭 번호와 오른쪽 도구 영역이 겹치지 않는다.
- 페이지 전환·선택 표시·세션 이름·대기 알림·단축키와 페이지가 하나일 때 탭을 숨기는 동작은 그대로다.
- 공개 API·타입·저장 데이터 변경은 없다.

검증: WorkspaceHeader·App 테스트 171개, 타입 검사, 헤더 너비 500~1400px의 브라우저 렌더링 30개 경우를 통과했다.
