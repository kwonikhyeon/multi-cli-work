# v1.45.2 — 페이지 탭을 이름 바로 옆에 배치

폴더·작업공간·숨김 화면의 페이지 탭을 이름 바로 다음으로 옮겼다. 이름과 탭 사이는 16px 간격을 두고, 레이아웃 선택·새로고침·세션 실행 버튼은 오른쪽에 유지한다.

- 긴 이름은 말줄임으로 표시하고, 오른쪽 세션 실행 버튼에 필요한 공간을 먼저 확보한다.
- 페이지 전환·선택 표시·세션 이름·대기 알림·단축키와 페이지가 하나일 때 탭을 숨기는 동작은 그대로다.
- 공개 API·타입·저장 데이터 변경은 없다.

v1.45.1은 CI에서 버튼 영역의 넘침이 발견되어 공개하지 않았다. 이 버전에서 공간 배분을 수정했다.

검증: WorkspaceHeader·App 테스트 171개, 타입 검사·빌드, 브라우저 렌더링 30개 경우, 세션 실행 버튼의 접근성과 겹침을 확인하는 Electron E2E를 통과했다.
