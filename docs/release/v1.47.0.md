# v1.47.0 — Google Drive 기반 업무 프로젝트와 설정 프로필

회사 문서가 Teams에서 Google Drive(`내 드라이브`)로 옮겨 감에 따라, 업무 프로젝트를 드라이브 폴더 기준으로 다시 짰다.

- **구분 코드**: 설정 › 프로젝트에서 각 구분에 영문 대문자 한 글자 코드를 붙인다(예: G 정부과제 · O 외주용역 · R 연구개발 · S 개인 · U 우리 · Z 기타). 코드는 업무 프로젝트·드라이브 폴더 이름의 접두어(`R_DOTORI`)라, 알파벳순 정렬이 곧 구분 순서가 된다. "코드순 정렬" 버튼으로 구분 목록도 맞춘다.
- **사이드바 정렬**: 업무 프로젝트를 구분 순서로 먼저 묶고, 같은 구분 안에서는 만든 순서로 놓는다. 머리 행을 끌어 같은 구분 안에서 순서를 바꿀 수 있다.
- **업무 프로젝트 페이지 재설계**: 머리에 구분 코드 배지를 두고 기본 정보 · 문서(Google Drive) · 코드 · 노션 · 데이터/참고 폴더 · 메모 카드로 나눴다. 이름 접두어가 구분 코드와 다르면 알리고 한 번에 고친다.
- **문서 · Google Drive 카드**: 업무 프로젝트 하나가 드라이브 최상위 폴더 하나다(이름이 같으면 연결). 폴더가 없으면 업무 템플릿(1.~7., Data, tmp, CLAUDE.md)으로 만들고, 있으면 문서 폴더로 연결하며, 하위 폴더를 칩으로 바로 연다. Teams·OneDrive에 남은 문서 폴더는 "드라이브로 전환"으로 같은 이름 드라이브 폴더로 옮겨 단다(세션·메모는 그대로).
- **프로젝트 만들기 대화상자**: 구분을 고르면 이름에 코드 접두어가 붙고, 드라이브 폴더도 함께 만든다. "드라이브에서 가져오기"는 다른 PC에서 만든 드라이브 폴더들을 한 번에 업무 프로젝트로 만든다(구분은 접두어로).
- **PC 루트**: 설정 › PC · 프로필에서 이 PC의 dev·data·work·Google Drive 위치를 지정하거나 자동으로 찾는다(C:/D: 차이). 레포 추가는 dev, 참고 폴더는 data, 문서 폴더는 드라이브에서 시작한다.
- **설정 프로필**: 설정·구분·업무 프로젝트·폴더·태그를 `<드라이브>\_config\multi-cli-work\profile.json`으로 내보내고 다른 PC에서 미리 본 뒤 불러온다. 경로는 루트 기준 논리 경로로 옮겨 PC마다 다시 풀고, 원격 설정·PC 루트·노션 토큰은 옮기지 않는다. 불러오기는 병합만 하며 직전 파일을 `profile-backups\`에 백업한다.
- 사이드바·멤버 목록의 문서 폴더 아이콘은 경로로 정해진다(Google Drive · Teams · 일반). 세션 브리프는 드라이브 문서 폴더를 "문서 폴더 · Google Drive"로 소개하고 드라이브 안 git 금지 규약을 함께 넣는다.

실제 Electron에서 Teams 폴더 전환·드라이브 폴더 생성·가져오기·접두어 고치기·PC 루트 화면을 격리 인스턴스로 확인했다. 전체 단위 테스트 2,091개, Electron E2E 34개와 타입 검사·프로덕션 빌드를 통과했다.

`work-projects.json`·`projects.json`의 형식은 바뀌지 않았다(드라이브 연결은 이름으로 정해지고, 새 설정 값은 관대한 `settings.json`에만 더했다). 구버전으로 내려가도 안전하다. 폰 앱(0.2.0)은 바뀌지 않았다.
