# v1.46.0 — 실행 중인 세션을 더 선명하게 표시

작업 중인 세션을 메인 창에서 바로 구별할 수 있도록 패인과 사이드바의 시각 효과를 강화했다.

- 패인 안쪽의 3px 청록 테두리를 따라 빛이 흐르고, 헤더에 회전 표시가 있는 **작업 중** 배지가 나타난다.
- 사이드바의 세션 패널·폴더 트리·숨김 목록에도 움직이는 청록 레일과 **작업 중** 배지를 표시한다.
- 바깥쪽 포커스 링과 실행 프레임을 따로 배치해, 선택한 패인과 일하고 있는 패인을 함께 구별한다.
- 작업 상태가 바뀌면 실행 효과가 즉시 사라진다. 입력·승인 대기, 오류와 완료 표시는 기존 동작을 유지한다.
- 헤더 아래 진행률 선은 실제 보고된 진행률이 있을 때만 표시한다.
- OS 또는 앱의 **애니메이션 줄이기** 설정에서는 움직임이 멈추고 정적인 프레임·배지가 남는다.

다크·라이트 테마와 12개 패인, 상태 전환, 진행률, 포커스·확대 모드, 애니메이션 줄이기를 Electron에서 확인했다. 전체 단위 테스트 2,022개, Electron E2E 34개와 타입 검사·프로덕션 빌드를 통과했다.

공개 API·저장 데이터·상태 판정 방식과 폰 앱(0.2.0)은 바뀌지 않았다.
