# v1.48.0 — 파일 목록 F5 새로고침과 폴더 즐겨찾기

외부에서 바뀐 파일 목록을 F5로 갱신하고, 자주 쓰는 레포 폴더는 즐겨찾기에서 바로 열 수 있다.

- **파일 목록 새로고침**: F5 또는 파일 탐색기 헤더의 새로고침 버튼으로 루트와 펼쳐 둔 하위 폴더를 다시 읽는다. 파일 생성·삭제·이름 변경과 Git·에이전트 변경 표시를 갱신하면서 펼침 상태와 선택한 파일을 유지한다. 1초 간격 감시나 포커스 복귀에 따른 자동 목록 조회는 하지 않는다.
- **F5 단축키**: 터미널에 포커스가 있어도 파일 목록을 갱신한다. 앱 창이나 세션을 다시 로드하지 않는다. 보기 메뉴에 파일 목록 새로고침을 추가했으며, 세션 새로고침은 세션 메뉴에서 계속 사용할 수 있다. 단축키는 설정에서 변경할 수 있다.
- **폴더 즐겨찾기**: 좌측 폴더 행의 별표로 추가·해제한다. 즐겨찾기는 프로젝트 트리 위에 표시되며 앱 재실행 후에도 유지된다. 사이드바를 접으면 즐겨찾기 폴더가 앞쪽에 별표로 표시된다.
- 늦게 끝난 이전 폴더 조회나 변경 표시 조회가 현재 선택한 폴더의 화면을 덮어쓰지 않도록 보호한다.

전체 단위 테스트 2,096개, Electron E2E 35개, 패키징된 Windows 앱의 F5·즐겨찾기·스모크·Codex 재개 테스트 12개와 타입 검사·프로덕션 빌드를 통과했다. 로컬 전체 단위 테스트는 Git 작업의 실행 시간을 고려해 테스트 제한을 10초로 실행했다.

즐겨찾기는 기존 로컬 사이드바 설정에 저장한다. 프로젝트 레지스트리 형식과 폰 앱(0.2.0)은 바뀌지 않았다.
