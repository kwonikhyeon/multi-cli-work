# v1.43.0 — 상태가 바뀌는 순간이 보인다

세션이 일을 마치거나 멈추고, 에이전트가 파일을 고치는 순간을 짧은 움직임으로 알린다. 장식이 아니라 상태 변화를 읽히게 하는 모션만 넣었다.

## 바뀐 것

- **완료·실패 신호**
  - 2초 넘게 작업하던 세션이 끝나면 패인과 사이드바 행이 한 번 green으로 빛난다. 오류로 멈추면 red로 빛난다.
  - 잠깐 돌고 마는 작업에는 빛나지 않는다.
- **보이지 않는 세션의 토스트**: 지금 페이지에 없는 세션이 일을 마치거나 오류로 멈추면 창 오른쪽 아래에 토스트가 뜬다. 토스트를 누르면 그 세션으로 간다. 토스트는 몇 초 뒤 사라지고, 한 번에 최대 3개까지 쌓인다.
- **에이전트가 고친 파일**: 탐색기에서 에이전트가 방금 고친 파일의 행이 violet으로 잠깐 물들었다가 빠진다. 파일이 접힌 폴더 안에 있으면 상위 폴더가 대신 물든다.
- **대기 맥동 구분**: 승인 대기는 입력 대기보다 빠르게 맥동한다. 사이드바 점도 패인 테두리와 같이 맥동한다.
- **홈 활동 피드**: 새 상태 전이가 위에서 미끄러져 들어온다.
- **다이얼로그·메뉴**: 설정 같은 다이얼로그와 우클릭 메뉴가 살짝 커지며 나타난다. 버튼과 행의 hover 색도 부드럽게 바뀐다.
- **애니메이션 줄이기**: 설정 › 일반에 새로 생겼다. 켜면 맥동, 빛, 진입 효과가 모두 꺼진다. Windows의 "애니메이션 효과"가 꺼져 있으면 이 설정과 상관없이 줄인다.

폰 앱(0.2.0)은 바뀌지 않았다.
