# v1.44.0 — 탐색기 파일은 Windows처럼 더블클릭으로 연다

우측 사이드바 탐색기가 Windows 파일 탐색기처럼 동작한다. 파일은 더블클릭해야 열리고, 기본으로는 연결 프로그램으로 열린다.

## 바뀐 것

- **더블클릭으로 열기**: 파일을 한 번 클릭하면 선택만 된다. 더블클릭하거나 Enter를 누르면 연다. 폴더는 지금처럼 한 번 클릭으로 펼친다.
- **연결 프로그램이 기본값**: 탐색기에서 연 파일은 Windows에 연결된 프로그램으로 열린다. HTML이면 브라우저가 열린다.
  - 설정 › 파일에 **기본 열기**가 새로 생겼다. 인앱·연결 프로그램·VS Code 중에서 고른다.
  - 확장자별로 지정한 값이 있으면 그 값이 우선한다.
  - 터미널에 찍힌 경로를 Ctrl+클릭할 때도 같은 기본값을 따른다.
- **앱에서 열기**: 앱 안의 뷰어로 보려면 파일 우클릭 메뉴의 **앱에서 열기**를 쓴다.
- **파일 탐색기에서 열기 버튼**: 탐색기 헤더에 생겼다. 지금 보는 폴더나 worktree를 Windows 파일 탐색기로 연다.

폰 앱(0.2.0)은 바뀌지 않았다.
